## 当前待办与暂缓项

三 CLI 原生能力补齐已合入本地 main。后续工作如下，实施过程见[历史追溯](engineering/decisions.md#历史追溯)。

| 项目 | 状态 | 继续条件 |
|---|---|---|
| 当前 URL/Key 的完整模型任务 | 外部条件阻塞 | Claude 本次请求预扣额度不足；Codex 用户并发上限；AGY 辅助模型无可用渠道。条件变化后再做有界复验，不自动替换模型或改写服务响应 |
| 账号登录模式 | 用户明确暂缓 | 当前使用 URL/Key；账号登录待单独验证 |
| AGY 实时上下文与逐 token 速度 | 未接入可靠数据源 | headless 未提供足够数据；内部流订阅的运行实例归属、计量范围仍需证明，不能用历史估计或字符数补造 |
| AGY 1M 下的实际生成预算与自动压缩点 | 相关修复已完成范围验证；裸 Argon 单次真实生成通过，精确触发时刻未压满验证 | 本地 High 对照确认内置名称碰撞及 256K 回退；真实裸 Argon 同轮确认 1M 覆盖、输入预算和 checkpoint 上限 934,464，模型输出上限为 65,536。生产启动的 High/Medium/Low 默认强度、显式覆盖和两轮续聊另经零外发模拟验证；不作为变体真实服务或满窗口承载验收。配置上限不能当精确触发点；Hydrogen 较早连接成功但缺同轮元数据的限制保留。反复修复的原因与验收改进见[复盘](engineering/decisions.md#传给原生的选择器必须是原生认得的标识) |
| Windows 外部会话链接 | 源码已接入，系统验收待做 | 下次制作安装包时验证协议注册、冷启动、运行中唤起和卸载清理 |
| MCP Apps 交互界面 | 用户尚未决定 | 当前仅管理 MCP 配置、工具及运行状态；承载远端交互界面需单独确定范围 |
| 新安装包、签名、发布及更新 | 暂缓 | 确定发布范围和版本后安排 |
| CLI 与环境兼容扩展 | 按需补验 | 新版本、其他输入法和服务器环境单独留证；Claude Windows 8.3历史/媒体读取已在cwd等价时补救；其他管理操作仍按原生SDK支持范围处理 |
| CLI 官方安装器实机升级 | 未对用户现有安装执行 | 安装执行与取消已用隔离子进程验证；Codex 原生发布服务在当前 Node 网络环境返回 HTTP 403，实际升级需官方服务可达且用户点击操作 |
| 未连接成功的 SSH 目标 | 一台连接失败 | 网络或认证条件恢复后再查；不跳过主机信任，不据另一台成功推定全部目标通过 |
