# 界面与交互

本文说明当前页面结构与交互。行为范围见[需求](requirements.md)，交付进度见[路线图](../roadmap.md)。早期三栏界面与验收见提交 `c686ef2`。

## 1. 桌面外壳

左侧是工作区和会话列表，中间是对话，右栏按需打开。Claude Code、Codex 和 Antigravity 共用同一界面，通过来源图标与名称区分。

| 区域 | 职责 |
|---|---|
| 左栏上方 | 品牌与收起按钮、新建会话、插件管理、已启用插件及更多操作 |
| 左栏工作区 | 项目树、按最近活动排列的会话、搜索及项目和会话管理 |
| 左栏底部 | 直接打开设置，主题在通用设置中切换 |
| 中央标题栏 | 当前会话标题、项目名称、对话/轨迹切换、子代理入口、运行/连接状态和右栏开关 |
| 对话主区 | 原生历史、实时事件、统计和消息输入 |
| 右侧栏 | 当前会话信息与选中执行步骤的输入、输出、状态和耗时 |

中央标题栏最小高 58px，窄窗允许换行，视图切换与标题同排。右栏每次启动时关闭；顶栏开关显示会话信息，点击轨迹步骤打开详情。插件使用中央主区，打开时隐藏右栏，返回对话后恢复本次右栏状态和草稿。

Windows 桌面另有一行 40px 应用顶栏，AgentDeck 与 File、Edit、View、Window 同排，右侧使用系统窗口按钮，保留拖动、缩放和原生菜单快捷键。浏览器调试隐藏桌面栏；弹出菜单不改变左栏布局，“更多”打开前后工作区位置保持不变。

### 1.1 宽度与收起

最小网页宽度 800px，1024px 为宽窄断点。左栏默认 280px，可调 264–420px，收起后保留 56px 图标导航；右栏默认 420px，可调 300–720px。对话区常规最小 400px，窄窗主动展开左栏时可降至 320px，并收起右栏；窄窗主动打开右栏时收起左栏，避免同时挤压中央区域。

窄窗临时收起左栏，保留用户保存的宽度与开合偏好。隐藏区的分隔线不可聚焦，关闭普通面板时将焦点还给可见入口。

## 2. 视觉和可访问性

- 默认浅色，保留深色选择及持久偏好。灰阶背景、细边框和少量高亮构成层次；路径与代码使用等宽字体。
- 主题变量集中定义在样式表，不在多篇文档复制色值。西文与数字优先使用内置 IBM Plex Sans，中文沿用系统字体，路径与代码使用内置 JetBrains Mono；正文默认 14px，辅助控件约 13px；CLI 使用来源图标和文字，状态不能只靠颜色。
- 图标按钮有可访问名称，键盘焦点清晰；菜单、对话框和分栏复用成熟组件。
- 应用图标采用蓝紫叠卡 A 图案，网页标签、桌面开发窗口及安装包保持一致；原稿与选用状态见 `apps/desktop/assets/branding/README.md`，使用与验收见[本地安装说明](../guides/local-installation.md)。
- 弹窗关闭后恢复触发点焦点；只有模态对话框限制焦点，普通面板不形成焦点陷阱。
- 兼容输入法组字和 `prefers-reduced-motion`。流式信息避免逐 token 播报，资源数值刷新不打断读屏。
- 标签、菜单、折叠内容与右栏采用短过渡；输入框显示轻微悬停光影，装饰层不接收点击，减弱动态跟随系统偏好。
- 新页面检查实际渲染、长标题、错误文案、缩放、键盘和辅助技术操作。

## 3. 项目与会话导航

点击项目行切换展开状态，并把该项目设为下次新建的位置；点击会话或标签才切换当前对话。项目菜单提供改名、换目录、移除和完整路径；桌面版另有「在资源管理器中打开」及系统目录选择，取消选择保留原路径。浏览器调试可手输绝对路径。离线项目仍可改名或移除，移除确认框明确保留磁盘目录与原生历史。

工作区行右侧提供“＋”，可直接选择 CLI 新建会话；当前工作区已有任务运行时也可新建。项目管理菜单仍可打开查看目录，修改动作及已打开的确认框在运行或准备发送期间禁用。更换当前项目目录后关闭其旧会话并清空参数覆盖，之后按新目录显示会话。处理其他项目的操作完成后不改变当前选择；未保存修改在离开时确认。

每个项目下混排三种 CLI 会话，默认按最近活动排序；工作区标题旁可切换名称或手动顺序。折叠时每个项目最多展示「设置 → 通用设置」里配置的条数（默认 5，可调 1–20），展开/收起只影响该项目；当前会话即使较旧仍保留在折叠列表中，搜索会显示全部当前查询结果。标题数字在搜索时表示当前结果数量，未搜索时表示已加载原生会话与本页临时会话数量；均不是 CLI 原生总数。任何排序模式都支持同项目拖动和 Alt+↑/↓，操作后保存为手动顺序，无需提前切换。首次移动以当前显示顺序为准，搜索只调整已知相关身份，分页外条目保留原有位置；只持久化排序身份。当前会话整行使用浅色底和描边高亮。来源图标和文字保留身份差异，搜索同时匹配项目名称、目录、会话标题和来源。读取中、读取失败与空列表应分别呈现，不能用「暂无会话」代替读取失败。运行、等待批准、未读、待发与草稿状态显示在工作区原会话条目旁。切换会话不插入额外区块；尚无原生 ID 的运行任务和关闭标签后的草稿仍可在所属工作区找回。

会话先展示近期一页，点击“加载更多会话”继续读取；搜索在服务端覆盖旧摘要，不只过滤当前屏幕。大量非匹配记录会分段扫描，仍可继续加载时不显示最终“无结果”。归档页、其他目录和会话搜索遵守相同浏览方式。项目名称变更后搜索结果随之更新。

未归属记录通过更多菜单中的「其他目录」按需发现，零项目也能使用。可信目录在条目下显示，可点击“加为项目”预填表单；没有可信目录的摘要不提供猜测入口。项目映射变化后同步更新归属，避免同一条目继续留在其他目录。

会话列表随启动及应用内操作自动更新，读取失败时在原处提供重试。更新列表时保留当前对话与模型目录。

新建会话先确定项目与 CLI，实际发送才创建原生会话。消息成功发送后，本页会话立即出现在所属工作区；原生 id 和摘要到来后按工作区与 CLI 身份合并，不生成重复条目。标题优先取原生标题，缺失时用首条已发送用户消息的预览；AGY 重启后可从原生摘要读回该预览。未发送的草稿不参与标题；原生历史连预览也没有时，列表显示「未命名会话」。运行失败也能从该行返回本页内容；原生摘要尚未出现的条目不提供管理或手动排序，其临时身份不写入持久排序。此补充导航来自页面内存；刷新恢复保留回合时可重建其入口，不代替原生持久化。三种 CLI 均可进入输入区；历史由对应适配器读取，失败在读取位置说明。

中央标题上方提供已打开会话的标签条，包含 CLI 图标、标题、状态和关闭按钮，可拖动重排、键盘切换，过多时横向滚动。关闭标签不删除原生会话、不停止任务，草稿和后台结果仍可找回；关闭或归档当前会话后选择相邻标签。插件或归档页上方仍可点击标签返回对话。普通标签和未发送草稿不跨刷新持久保存；恢复缓存中的回合会重新建立标签。输入区只显示来源图标和具体型号，完整目录与原生 id 可在右栏查看。

## 4. 对话主区

### 4.1 历史与流式事件

历史与新回合使用一致的消息与工具行。用户消息使用靠右的圆角气泡，助手正文直接排版，用户提问与已完成助手回复悬停或聚焦时提供轻量复制入口；思考过程、工具与活动均采用统一折叠卡片，收起时以单行展示动作、截断参数、状态和耗时，公开说明、完整参数和结果放在展开内容中。读取/搜索组同样保持单行，窄窗优先保留失败与未完成状态。文本、代码、工具参数与结果均来自原生事件；读取类工具可合组，审批、执行和失败保持独立。

正文宽度根据中央列计算，默认目标宽度为 `clamp(680px, 64cqw, 920px)`，实际不超过可用区域；输入框外沿比正文宽 32px。设置里选定宽度后改用固定像素：小 720、中 860、大 1040，或 480–1400 的自定义值，默认「中」；读不到设置时退回按容器自适应。打开右栏后仍保持消息与输入的共同轴线，长路径和代码不能撑破布局。

实时回合需要支持跟随底部和回到底部；用户向上浏览时不强制跳回。展开工具详情、长代码块和布局变化后保持合理滚动位置。长列表的实现预算见[架构](../engineering/architecture.md)。

对话右侧提供用户消息刻度，悬停预览提问，点击定位对应用户消息；方向键与 Home/End 可切换刻度后按 Enter 跳转。刻度按实际视口高亮，长会话只挂载可见窗口，滚动或键盘能访问其余提问。主动跳转暂停贴底跟随；“回到底部”在对话与轨迹中都使用实体主题背景，避免正文透出。

加载中、空历史、读取失败与旧版本返回的不可回放状态分别处理。切换会话先取消旧读取并隔离迟到结果；失败在原位置解释并允许重试。Codex 和 Antigravity 主会话先显示最近内容并定位到末尾；空闲时若提问不足，继续有限补读，便于从右侧定位最近提问。更早记录可向上滚到顶端加载，也可直接点击右侧导航上方的箭头，无须先滚过长回复；首屏只有回复片段时仍保留入口。新页接到上方并保留当前阅读位置；较早页失败不清空正文，顶端与右侧入口均可重试。对话和执行轨迹共用已加载的历史，子代理保持独立。

Antigravity 续接结果的归属存在冲突时，把线索留在对应轮次详情；如果待发因此暂停，在待发区提供「查看原因」。明确的本轮故障仍在该轮对话展示。[回合判定](../engineering/native-dialogue.md#headless-回合结果)由原生对话接入维护。

AGY 没有返回文字时，在对应轮次说明并保留工具记录。

能核实原生响应型号时，在对应助手回复下方用小字显示“响应模型：型号”。切换下一轮模型不改旧回复标记；无报告时不显示占位提示。Claude 随消息显示，AGY 历史按生成步骤恢复，headless 结束后复用有界补读；ACP 实时没有可靠步骤对应时，重新读取历史后才能显示。Codex 当前协议无法确认每条回复型号，保持缺省。具体证据见[能力矩阵](../engineering/native-capability-matrix.md)。

工具报告的路径和动作在对应步骤中查看。

三个 CLI 的已有会话均在对话视图切换旁提供“子代理”入口。打开后按需列出已核实父子关系的原生摘要，展示可取得的名称、角色和状态；缺失状态显示未知。可切换独立对话或轨迹、继续加载、进入下一层子代理和返回上级，刷新重新读取快照；步骤与图片详情在独立弹窗内显示，关闭内层弹窗保留外层历史。子代理记录不插入主对话，不改变主会话统计、草稿、分叉点或右栏选择。活动任务的查看与停止使用[会话原生任务](#会话原生任务)面板。

输入区提供图片/文件选择、粘贴与拖放，显示文件名、准备状态、缩略图、移除和失败重试。删除上传中的附件会取消网络请求；切换项目后，迟到结果只更新原会话。纯图片可以发送；能力不支持、格式错误或上传失败时保留文字和文件。发送后的拒绝或恢复失败保留上一条文字与附件；已有新草稿时提供互换恢复与显式放弃入口，未知送达仍需先核对原生历史。页面身份或上传所属会话变化后，保留本地文件并提示显式重传，不复用失效的引用。

使用个人 Google 账号登录 AGY 时，可在新会话或同账号的可续接会话里贴图。发普通文字仍用原来的方式；如果模型、权限或这条会话不支持发图，输入保留，可以移除图片继续。

对话中的图片可点击放大并按 Esc 关闭；文件显示名称。历史图片按记录的项目、CLI、父会话与子代理身份定位，不借用当前聊天的上传凭据；文件丢失或格式不支持时显示原因，不显示破损图标，不将图片字节放进工具正文。

输入 `/resume` 打开“继续会话”，也可以输入 `/resume 会话标题或 ID` 带入搜索。只列当前项目和 CLI 的未归档会话，显示原生 ID 以区分同名记录；支持上下键、回车、点击及继续加载。Esc 取消时保留输入；选中后只清掉用于打开选择器的命令，不移走附件、不打断原会话。下一条消息仍由用户发送。AGY 还支持 `/switch`、`/conversation`，Claude 还支持 `/continue`；斜杠补全将它们标为工作台命令。

### 4.2 执行轨迹与用量

“对话 / 轨迹”共用同一会话内容。轨迹按用户轮次排列步骤，显示类型、执行内容、状态和已有耗时；命令、文件、读取、搜索、MCP、审批等保持原生顺序，未知步骤显示为活动，不伪装成工具。长回合逐步骤虚拟化，选中行在右栏查看详细输入、输出或错误；实时轨迹中的未处理审批仍可直接答复，底部保留输入和停止按钮。独立子代理历史的对话、轨迹和步骤详情只展示已有的权限或提问记录，不提供审批、提交回答或分叉。

输入框下方左侧显示平均 tok/s 与耗时，右侧显示上下文用量；缺值用「—」。点击展开 token 分项，已加载的历史统计可在轨迹中查看。本轮暂无有效速度时保留同一会话最近已加载的有效值，标记「最近一次」。悬停及详情区分回合均速和步骤均速，计算和补读条件见[统计口径](../engineering/cli-observability.md#计量规则)。

上下文按钮位于输入框外下方，显示已用量、有效窗口和占比圆环，并保留百分比；达到 90% 时使用警示色，超过窗口时圆环封顶但百分比保留实际值。未知字段显示横线。Antigravity 用量来自原生估计，窗口只显示当前所选模型生效的总容量，打开旧会话也不并列旧窗口；运行中采用启动快照。没有本轮实时报告时，结束后有界补读原生用量。压缩进行中显示进度，失败与未确认状态可在详情查看；过去已完成的压缩只留在消息轨迹。

复制会话链接成功后显示短暂浮动提示，不占列表行、不移动焦点；剪贴板不可用时才显示手动复制输入框。

轨迹提供「全部 / 上下文 / 用户 / 工具 / 助手」筛选，每条以单行排列图标、角色、动作摘要、状态和耗时，长文本截断并可打开全文详情；默认行高约 36px，统计也以单行摘要呈现。筛选保留原生顺序和轮次；上下文只有最近用量报告和已有压缩事件，不伪装成 CLI 未提供的完整提示词。思考、回复、活动和统计归于助手，工具与审批归于工具，实际失败状态继续保留。

### 4.3 输入与原生参数

输入区采用统一圆角容器，底栏左侧放技能与命令、权限，右侧放模型、推理强度及圆形发送/停止按钮；原生上下文与用量摘要位于容器下方。发送需要明确操作；输入法组字时不提交，忙碌时避免重复发起同一会话回合。

运行中仍可输入文字、上传附件并选择下一轮技能、模型和推理强度。Enter 加入待发，底栏只保留独立停止操作（本地会话命令仍可执行）。运行快照支持引导、队列未暂停且参数与本轮一致时，Ctrl/Cmd+Enter 引导当前草稿；待发条目的上箭头只引导这一条。失败不自动改为排队。权限入口在运行中锁定；新会话预选该 CLI 保存的默认权限。

待发消息在输入框上方逐条显示，可编辑、移除或按当前原生能力引导；暂停时保留显式继续。编辑 queued/failed 的排队条目先由服务端确认移出调度，再取回到输入框；原有草稿单独保留。受理未确认的条目不可编辑或自动重发，移除须确认且不会撤回原生可能已收到的内容。原生回合结果未确认且仍有待发时，待发区说明暂停，并通过“查看原因”打开对应轮次详情，不自动发送下一条。仍在排队的内容不提供复制恢复；失败、未知或失效备份核对历史后可恢复草稿，保留现有草稿和旧附件恢复入口。回执到达后只清对应输入；本页 File 保留到受理或移除，连接身份失效后必须显式重传。刷新可恢复服务器未决文字，浏览器 File 与普通草稿不跨刷新持久保存。

Codex 非阻塞问题复用问题表单，标明回答默认排队；本轮结束后仍可回答，切换会话后保持原归属。提交、错误重试与关闭只影响该卡片，不覆盖输入框草稿；原生历史已答题显示已回答。

模型和推理强度默认沿用原生值；菜单优先采用原生报告，未报告时仅按精确型号补充有依据的档位。选中会话即读取缓存，菜单候选在首次打开模型或强度菜单且无缓存时才调用原生发现；打开已有缓存不显示整块加载提示。AGY 临时窗口启动另可在发送准备阶段读取隔离的本机目录以保持默认强度，该读取不发送模型请求。Claude 模型菜单单独提供“默认窗口 / 1M”，后缀由用户选择或继承原生配置；打开菜单不自动开启，切换保留已选强度。`[1m]` 原样发送，按钮另显示 1M 标记，实际占用仍采用原生报告。

模型菜单先列少量可见候选并保留当前选择，超过首批数量时通过“搜索可见模型”查找名称或真实型号；长结果按需展开。可见范围在设置中按 CLI 选择，AGY 另按已保存的连接方式区分，Codex 为已核实的 ChatGPT 模式保存独立显示范围；当前型号即使未勾选也保留，避免隐式切换模型。检索只使用已有缓存，不重新发现账号或发送请求；键盘可选中结果，关闭后返回模型按钮焦点。

模型入口显示 CLI 图标与下一轮选定的型号，没选时显示当前 CLI 默认的具体型号（有报告时）。最近一次原生报告在菜单内另列，不自动填入下一轮。AGY 使用带档位的型号；其他型号只有 CLI 返回可用档位时才有独立强度入口。重置模型放在更多操作里，也可手填型号；重置强度后不发送覆盖。已有候选在刷新时保留，出错显示当前模型目录的原因。AGY 菜单仅复核连接身份；识别到连接且没有可复用目录才自动发现。AGY 官方账号和 Codex 原生 ChatGPT 登录可按需查询官方额度，API Key 模式不显示该入口。

### 4.4 运行、审批与结束

运行中在输入框上方持续展示本轮阶段与已用时间，对话和轨迹共用。准备、等待模型响应、思考、生成回复、工具执行、等待批准和停止按本轮事件推导，结束后清除；旧回合工具与审批不影响新回合。工具卡片显示中文动作，并在原生提供时显示公开说明或进度文字；未提供的思考正文或工具说明不补造。停止可覆盖准备和生成阶段。CLI 发出交互审批时，在对应回合显示批准、拒绝与取消操作；AGY 的文字兼容路径仅在实际软拒时显示原因。

运行与页面选择分开：任务进行中仍可查看另一会话、切项目、新建并发送其他任务，或进入插件与归档页面。左侧后台入口显示运行、等待批准和未读结果，原生 id 尚未返回时也可点击找回或单独停止；窄窗以图标入口保留访问。草稿和对话/轨迹选择随会话恢复，同一会话不能重复发送。项目目录修改和移除只锁定正在使用该项目的任务，不阻止普通导航。

页脚显示运行和连接恢复等影响当前操作的状态。主动停止后保留已有内容，待发保持暂停。短暂断线补收与刷新见[恢复边界](../engineering/architecture.md#44-历史与前端状态)；缓存恢复结束后可重新读取原生记录，AGY 先读最近页。

分叉与删除等操作只有在对应原生能力已接入且会话空闲时出现；删除明确二次确认，分叉使用原生结束点，不承诺回滚文件。

每个会话的“更多”菜单依据服务端能力显示重命名、创建分支、归档和删除，键盘到达该行时入口可见。统一归档页合并 Codex 原生归档与 Claude/Antigravity 工作台归档；后两者保留 CLI 记录，仅从工作台活动列表移出。归档后先恢复再续聊；删除确认说明实际影响的会话及子记录。操作完成刷新同来源列表，迟到结果不抢占当前选择，其他项目的首次加载不能因查询取消而停住。未归属条目沿用添加项目后管理的流程。

已归属工作区的会话菜单统一提供“复制会话链接”，运行中也可复制；原生 ID 在右栏详情中可选中复制。链接使用稳定的 `agentdeck://session`，包含工作区、CLI 和原生 ID，不依赖后端端口。聊天正文中的完整链接与输入区的引用条目可在当前窗口定位，旧网页片段链接仍兼容。桌面系统级打开由安装版协议注册提供，开发模式不会争抢系统协议。

## 5. 设置

Antigravity 的“服务连接”直接提供一个“AGY 代理地址”，保存后下次启动 AGY 时生效，不需重启 CLI；清空并保存恢复默认。已保存为账号登录时，在同一区域显示原生确认的 Google 账号邮箱，旁边提供“重新登录 Antigravity”。Windows 桌面端打开原生登录终端，授权码粘贴回发起登录的终端；终端结束后重新读取账号。无桌面桥接时显示本机命令。未能确认邮箱时不显示为退出登录，API Key 模式不显示账号行。

鼠标光影仅在聊天输入框内跟随鼠标，默认开启。通用设置只提供开关，保存到本机产品配置后重启保留；浅色主题使用淡灰蓝阴影，深色主题使用柔和亮蓝光晕，颜色与强度自动适配。装饰不影响输入、点击和文字选择，移出输入框、失焦或页面隐藏时收起，触摸、减少动态效果与高对比度模式不显示。

输入区识别会话引用后显示可打开的引用条目。发送时附上对应原生记录位置和读取说明，当前会话继续使用自己的身份。重读历史时，附加说明收进“引用记录”，普通消息复制只取用户正文；需要完整原生输入时可从详情复制。详情中的原生 ID 仍可用于原生命令。

Codex 模型设置将“上下文窗口”和“自动压缩阈值”分别显示为数字输入，单位均为 tokens；清空恢复原生默认，不把 Claude 的 1M 选择复用到其他 CLI。

设置分清产品偏好和 CLI 原生配置。默认 CLI、主题等属于工作台；模型、Skills、MCP、原生插件与记忆控制属于对应 CLI；会话权限的显式选择由工作台按原生身份记忆，实际执行仍遵循原生模式。

模型页的“对话菜单中的模型”属于本机工作台偏好，按 CLI 勾选；AGY 的账号与 Gemini API 分开保存，旧共用范围保留但不自动套用。范围与模型表单一起由底部“保存配置”提交，支持搜索、全部隐藏与恢复全部。勾选只改草稿，未保存时列表标注“保存设置后生效”，离开设置同样经过未保存保护；不逐次自动保存，避免连续点击互相覆盖。未设置范围时展示全部已获取候选；设置范围后，新获取型号不会自动加入；如果范围隐藏了候选，对话菜单显示隐藏数量与设置入口。当前型号继续可见，筛选不修改原生默认、模型目录或已有会话参数。保存后立即应用，重启可读回；保存冲突需重新读取，迟到响应不覆盖较新的设置。清单与对话菜单共用同一模型身份合并，原生别名不重复占行，保存的仍是可发送的原生 id；候选列表随设置页滚动，不另设内嵌滚动区，超过一次展示上限时在列表外提示剩余数量。

设置使用完整页面并保留桌面顶栏，返回工作台恢复会话、草稿与已打开的插件；后台回合继续运行。左侧列出通用设置、快捷键、模型与连接、Skills、MCP、原生插件、原生文件、记忆和运行环境；模型与资源页顶部选择 CLI。设置管理用户级原生配置，项目级配置由各 CLI 的项目文件维护。常用模型、地址与认证优先显示；模型别名折叠，原生文件与启动变量分别从「CLI 配置文件」和「CLI 环境变量」进入。

设置页增加“记忆”分类。Claude 的记忆页只切换用户级 Auto Memory 开关，不读取记忆正文，项目级启用仍由项目原生设置决定；Codex 与 Antigravity 显示已登记的规则文件入口，不出现未经验证的通用开关。

配置按「这个 CLI 支持哪些项」呈现，再显示其真实作用域。没有项目级配置的项不画项目级空表单；目录级规则、运行时参数也不能强行合并成用户/项目两层。原生配置读取失败、文件不存在和空白文件分别说明。

Skills、MCP、原生插件分别提供独立管理页；“原生文件”集中提供规则、Hooks、代理定义与完整配置编辑。编辑、创建和环境变量使用页面内详情，分类、CLI、项目与返回工作台共用未保存保护；离开时卸载敏感正文并取消旧读取，没有设置模态弹窗或焦点陷阱。Skills、MCP 和原生插件默认显示全局；有当前工作区时另有工作区页，只列项目来源以及真实可写位置。资源用紧凑平铺行显示名称、可用简介和必要状态，点整行进入页面内详情，不在列表中嵌套折叠。新增与导入合到“添加技能”，路径、编辑和连接检查放在对应详情。进入页面或保存后自动更新目录，读取失败时在错误旁提供“重试”。文件编辑时的冲突重读独立保留。

Skills 默认只展示该范围的已安装技能，插件提供和内置来源另列。CLI 识别的套件子技能从所属技能详情查看，也能按名称或简介搜索。简介优先使用原生条目，也可读取技能自己的 `SKILL.md` 元数据，没有就留空。工作台发现的文件不标为 CLI 已加载。Claude 的项目共享和仅我按实际配置区分；Codex 用户级技能启停不放进工作区页。

原生插件安装与市场增删先显示来源、作用域及影响预览，再显式开始。原生要求命令确认时显示命令全文，SHA-256 收进“命令校验值”详情；勾选允许后才能继续，提交仍校验完整摘要。关闭设置不取消任务，重新打开恢复执行、等待确认或未能确认完成的状态，取消按钮独立。CLI 与项目切换隔离任务。市场刷新按指定来源执行，不等同于单插件更新；没有原生更新接口时不显示更新按钮。Claude 配置值默认隐藏且不回填，空白保留旧值；配置冲突保留当前输入和原 revision。安装成功和已启用分别呈现。

MCP 面板按来源与作用域显示配置，提供支持的传输、新增、编辑、确认删除及持久启停。URL、参数和秘密不回填；环境变量、请求头的保留、替换和清除有独立选择，秘密新值默认隐藏并可显式显示。外部修改冲突保留原草稿与 revision，取消编辑后可采用刷新结果。插件 MCP 只读并标明所属插件。

MCP 列表按各 CLI 的原生来源展示和管理配置。会话引用的读取方式见[原生对话接入](../engineering/native-dialogue.md#41-会话引用读取)。

读取 MCP 列表不连接服务。用户显式检查后才展示工具目录、认证与连接状态；同一实例与配置的检查结果在当前 MCP 页内保留，返回列表不重复连接。项目实例接口支持在绑定实例中重连、启停或重载配置，与持久开关分别标示；工作区有活实例时，可直接选择“运行实例”。Codex 无线程查询的未知连接状态不显示为已连接；AGY 只展示持久配置，不填入连接状态。Codex OAuth 提供原生链接、等待完成状态与取消，打开链接不等于成功；重新打开设置可恢复未完成操作。Claude 持久 MCP 登录需要原生交互终端，对话内 URL 授权继续使用问题卡片。

原生文件按 CLI 和真实作用域浏览，同一个文件只有一个入口，不因用途不同而重复登记。主列表显示已有文件的名称和路径；未创建的预设文件与可新建的目录放在“新建文件”里。只读和实际读取失败仍在对应行标注。目录不读正文，点击文件才打开完整原文（含敏感值）；离开清空正文，保存冲突保留草稿并提供重读。

模型表单只修改对应用户原生配置，秘密只显示“已设置”状态，空输入不擦除已有 Key；清除有独立操作。切换分类、重新读取或退出时保护未保存修改，保存期间不重复提交。模型能力缓存随保存失效，旧请求的成功、失败和忙碌状态不能影响新配置。

Codex 高级设置将认证选项称为“凭据获取方式”：直接填写 API Key、从环境变量读取 API Key、沿用 Codex 登录，选择一种即可。环境变量输入只填写变量名；原生认证可来自 ChatGPT 或 API Key 登录。来源及变量名的帮助直接展示，保留已有高级认证的原生编辑入口；不要求重复填写密钥。

设置页提示遵循[用户可见提示](#71-用户可见提示)。字段补充信息放在对应字段旁，复杂说明按需展开；保存失败、草稿丢失和删除范围在受影响的操作旁说明。

模型页统一提供连接、模型候选和对应的运行参数，API Key 用圆点占位并提供更换、清除；Antigravity 的 Gemini 地址与密钥直接在同页填写。模型页和 CLI 环境变量页的密钥输入框右侧提供小眼睛按钮：有新输入时显示新值，否则按点击读取已保存的 Key；只有新旧值都不存在时才禁用。查看不产生未保存修改，隐藏、保存、切换配置或清空草稿后恢复遮蔽；读取失败可再次点击重试。URL 和 Key 保存后下次发送生效，已有会话下次发送也会重新加载连接，无需重启应用。AGY 打开本机旧历史不以连接分类；换连接后能否续发仍由原生 CLI 和当前模型决定。高级 CLI 环境变量页保留独立的“重新启动 CLI”操作。模型目录复用缓存，获取前若有改动，按钮明确写“保存并获取模型”。名称、推理强度和窗口按各 CLI 支持的字段展示，不做无效通用字段。仅内容区滚动，页脚保存按钮固定，焦点环位于输入框内。模型建议及固定选项使用统一浮层，允许保留自定义型号；浮层挂在所属原生对话框内，自动翻转和限高，不参与表单布局。第一次 Esc 关闭列表，下一次退出设置，方向键浏览不提前写回配置。

原始配置、模型别名及启动环境收进高级设置；规则和 Skill 仍在原生根目录中创建。高级启动变量保持原有语义，已有会话可在空闲时重新启动 CLI。常用页面不罗列变量来源与继承状态。

Antigravity 的默认模型建议、对话菜单与模型搜索共享身份合并规则：同名原生条目和明确指向它的唯一自定义别名合并显示一项；缓存同时含型号 ID 与该型号的显示名记录时，两者也合为一项。真正不同的同名型号或多个配置入口分别保留。对话菜单应用显示范围并保留当前项，按钮和菜单采用一致的型号显示；原始型号和配置名称都能搜索。打开菜单不改变选择；点选已有显式选择时保留其值，原生名称与其他模型的配置键重名时则使用对应配置项，保持实际模型一致。显示范围同时识别合并项的各个身份，取消勾选后整项隐藏。设置建议对未合并的同名项附上 ID，完整模型目录、强度变体及显示范围配置仍保留各自身份。

## 6. 工作台插件入口

从左栏的插件管理安装、启用或停用插件，已启用的插件可从同一侧栏打开。页面切换与启停的区别、包权限及具体插件用法见[工作台插件](../engineering/workbench-plugins.md)。

插件可声明侧栏页面、设置入口以及输入和会话操作。设置入口显示在设置左栏，打开后可返回设置；输入和会话命令集中在输入区的“扩展操作”，没有对应插件时不显示入口。后台命令保持当前页面；插件修改草稿后由用户发送。

获得会话控制权限的扩展可续接已打开的会话。后台标签收到结果时保持当前页面，输入区已有草稿继续保留；正在运行或已有待发输入时，先完成原来的交互。

## 7. 命令与反馈

`Ctrl+K` 包含项目、会话、设置、侧栏收起与已启用插件声明的命令。插件命令打开对应页面并交付命令 id。

快捷命令支持上下选择、Enter 执行和 Esc 退出，输入法组字期间不触发。连接断开时提供明确的恢复入口。

### 7.1 用户可见提示

先判断要不要显示，再决定怎么写。以下规则适用于整个应用。

- **没有实际影响，不打扰。** 正常完成、自动刷新、不影响当前操作的内部未知状态，不额外加横幅、页脚标签或弹窗。没有数据的字段可显示 `—`，不为缺省数据再弹一条解释。不要用「待核实」「结果未确认」「请核对原生记录」作通用标签或兜底。
- **有影响，就说发生了什么。** 用简短、具体的中文说清哪个操作受影响、现在是什么状态；如果用户可处理，给一个真正能做的下一步。协议名、退出码和原生诊断留在按需展开的详情，不用泛泛的「检查配置」代替具体建议。不知道原因就说已知影响，不猜测。
- **一件事在最相关的位置说一次。** 附件被拦就提示在输入框旁，待发暂停就提示在待发区，保存失败就提示在对应设置里。同一原因不同时堆到页脚、弹窗和轨迹；需要追查时由该处进入详情。回合报错只显示主要原因，中途已恢复的限流不另显示；工具自己的失败留在工具卡片。
- **不省掉真实风险。** 没发出、可能已发出、确定失败是不同状态；缺数据不是零。可以不展示内部状态名，但不能放开暂停、自动重发或把未知当成功。涉及权限、丢失草稿、凭据或不可逆操作时，保留具体对象和后果。

聊天页仅在当前所选 CLI 不可用或环境读取失败时显示环境提示，其他 CLI 缺失留在运行环境页。恢复失败在受影响会话中说明，不同时增加全局横幅；空闲连接身份自动更换不提示，容量阻断和回合外待处理交互失效仍提示。待发项与列表的相同原因只显示一次，发送状态不明仍标为“可能已发送”，不自动重发。

Skills、MCP、插件和原生文件的正常列表不附带通用免责；实际读取失败、部分结果和不可操作原因保留。原生能力、记忆版本与生效范围、MCP 登录步骤和连接详情按需展开。保存成功由状态变化或一处简短反馈体现，不再要求核对正常结果；未保存草稿与外部修改冲突就地提示。

| 实际情况 | 推荐表达或显示方式 |
|---|---|
| 续接结果的错误归属不明，用户无需处理 | 把异常线索留在对应轮次详情 |
| 待发因续接结果的归属冲突而暂停 | 在待发区说明暂停并提供「查看原因」，链接到对应轮次详情；原因变化时更新说明与入口 |
| 无法判断某条消息是否已发出 | 「这条消息可能已发出。」提供「重新读取会话」；不提示直接重发 |
| 当前 AGY 会话不能直接接收图片 | 「当前 AGY 会话不能直接发图。可在原生 AGY 终端粘贴图片。」不解释 headless 或 ACP |

参考：[Microsoft 错误消息指南](https://learn.microsoft.com/en-us/windows/win32/uxguide/mess-error)（避免无用提示）和 [GOV.UK Design System 的错误提示规范](https://design-system.service.gov.uk/components/error-message/)（说清发生了什么、如何处理；不把用户无法修正的问题写成输入错误）。

## 会话权限入口

权限菜单在输入区底栏左侧，按当前 CLI 显示可选模式。选择后立即显示具体模式名称，保存期间暂缓发送，失败恢复旧选择并保留错误状态。手动选择同时设为这个 CLI 的新会话默认，重启后仍保留；切换 CLI 时使用各自的选择。已有会话只恢复自己的设置，不受新默认影响。尚未选择时显示“选择权限”，不把未读取的原生配置猜成某个模式。点“重置权限”恢复当前会话的原生权限，并清除同一 CLI 的新会话默认。已有 Codex 会话的显式重置仍会在续接时读取并恢复当前配置。权限读取失败可重读，保留未发送的草稿。

## 快捷键与会话搜索

“更多”中的“搜索会话”和快捷键打开同一个搜索弹窗，结果按工作区分组，只列会话。按标题、原生 ID、CLI、项目名称或目录匹配连续文字片段，不区分大小写。旧摘要继续使用服务端分页，当前已读会话的标题也参与匹配。

“设置 → 快捷键”集中提供新会话、搜索、标签切换与关闭、聚焦输入、设置和侧栏操作，所有工作区与 CLI 共用。点击按键录入新组合，Esc 取消，清除即停用；可恢复默认。保存后重启继续使用。已占用或系统编辑组合在录入位置说明；输入法组合输入、原生弹窗、终端和插件页面保留各自键盘行为。扩展命令从扩展自己的入口或插件管理中的“操作”菜单执行。

官方额度再次打开时先显示上次结果和读取时间。结果保留一分钟，过期才在后台更新，手动刷新立即读取；刷新失败保留已有结果。检测到对应 CLI 的登录或连接配置变化时清除其额度缓存。

## CLI 安装与更新

安装与更新统一放在“运行环境”页，三个 CLI 各有一张版本卡片，模型与连接页不重复提供。卡片显示当前版本和手动检查到的最新版本。“检查更新”显式联网，未检查、版本未知和查询失败都不能显示“已是最新”。检测到缺失时提供安装入口，点击后先检查官方版本再安装；有新版时提供“更新”。入口缺失、版本读不出或程序与包清单不一致时，能确认归属的安装提供“修复”。版本正常但工作台接口不兼容时显示原因和官方指南。更新目标正在使用时，提示用户关闭对应会话后重试。无法安全操作时显示原因和官方指引。

操作中显示安装、更新、修复或验证进度；关闭设置不取消后台任务，再次打开继续显示结果。只在任务活动时刷新进度，不在空闲时轮询或自动安装。工作台正在使用当前 CLI 时禁用安装、更新和修复。另一个 CLI 正在维护时仍可查新，写操作需等当前维护任务结束。成功后刷新环境与模型能力缓存，不覆盖未保存的配置草稿；失败留在卡片中，可重新检查后重试。

## 原生提问与表单

对话和执行轨迹共用提问卡片，支持原生选项、自由回答及表单校验。回合等待期间显示“等待你的回答”；后台会话的待答状态可返回处理。没有活动回合的原生表单显示在独立收件卡片中，保留 CLI、项目和原生服务来源。

秘密字段只在未提交表单中出现，收到回执后卸载输入控件；已提交卡片不展示答案。取消、拒绝和提交分别使用原生动作。授权链接显示目的域名，点击才打开；“已提交”与“原生服务已确认完成”分开呈现，不将打开页面作为授权成功。卡片使用通用主题颜色与响应式宽度，支持键盘选择、填写和提交。

## 会话原生任务

对话输入区旁的原生任务面板显示当前会话所属实例的子代理与后台命令，单项状态不并入父回合统计。存在实际停止能力时提供停止按钮，并等待原生状态更新；停止后保持面板展开以便核对结果。切换会话只显示对应任务，连接身份失效后禁止旧任务控制，历史子代理仍通过独立历史弹窗读取。
