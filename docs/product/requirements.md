# 产品需求

本文定义产品方向和验收条件，交付状态见[路线图](../roadmap.md)。早期 M1 需求与验收记录见 `git show c686ef2:docs/product/requirements.md`。

## 1. 定位与范围

AgentDeck 面向在 Windows 本机使用多个 AI CLI 的用户。以 DSH 式桌面工作台集中组织项目、原生会话和对话操作，自有插件承载附加工具。原生对话与配置始终是产品主体，插件不改变各 CLI 的执行语义。

主体负责项目导航、CLI 接入、会话呈现和通用交互。Claude、Codex 与 Antigravity 共用一套工作台和对话界面，来源与实际支持能力各自保留。CLI 仍负责模型调用、上下文、工具、权限规则与原生存储；插件负责附加业务。

不在当前范围：多用户服务、局域网或公网访问、跨 CLI 转换会话、多 Agent 编排平台、内置 IDE、代码同步、本地版本快照与文件镜像。无需安装 DSH 插件包，也不建设 DSH 兼容层。

## 2. 功能要求

### F1 项目与目录

- 项目以本地绝对目录为身份，新增或换目录时校验目录存在；目录暂时离线时显示提示，已有项目仍可改名或移除。
- 桌面添加与更换工作区支持系统文件夹选择，取消保留已有路径，并防重复窗口及迟到结果；浏览器模式保留手动填写。
- 移除项目只删除 AgentDeck 中的记录，保留目录、原生会话和独立的服务器档案。
- 项目记录包含 `{ id, name, dir }`，服务器档案由 SSH Console 独立管理。
- 项目菜单独立提供改名、换目录和确认移除；修改时只提交需要更新的字段。所属项目有会话运行、准备发送或管理时禁用冲突的目录变更和移除；服务端对目录修改和移除建立原子占用边界。
- 换目录后清理该项目的旧会话选择、模型和能力缓存，再按新目录读取列表。异步操作完成时不得切走用户后来选择的其他项目。
- 工作台从生效的数据目录读取当前格式的配置。

### F2 原生会话发现与归属

- 会话身份由 CLI 类型与原生会话 id 组成，创建后不能切换成另一种 CLI。
- Claude 和 Codex 以原生 `cwd` 归属，Antigravity 使用 `workspace_uris`。规范化绝对路径后比较目录或子目录；Windows 大小写不敏感，POSIX 保持大小写。
- 多项目命中时取项目配置顺序中的第一个；解析不出或不属于任何项目的记录归入「其他目录」，默认隐藏。只有服务端能确认单一本机绝对目录时，条目才提供预填的添加项目入口；远程 URI、歧义和未知目录不猜测。
- 「其他目录」按需读取，零项目时也能发现原生摘要；新增、换目录或移除项目后同步刷新归属，不让已归属会话仍留在无归属缓存中。
- 主界面按来源分页读取近期摘要，继续加载与搜索可以访问旧会话；项目增加不能成倍触发全量枚举。查询变化和管理结果不能混入旧页，缓存回收不得让已有型号或草稿消失。
- 列表默认按已加载记录的最近活动排序，也可选择名称和手动顺序；标题取原生摘要，缺失时用已发送的首条用户消息，再缺才显示「未命名会话」，不能按标题猜模型、目录或会话身份。原生标题为空时不编造占位文案，未发送的草稿也不作为标题。工作区展开不切换对话，当前会话高亮；顶部标签可切换和关闭已打开会话，关闭标签不删除历史或停止后台任务。
- 读取、续接和管理操作前复核会话归属。切换选择时取消旧读取，迟到结果不能替换当前会话。
- Claude/Codex 从官方会话接口读取历史。Antigravity 通过本机原生服务读取已适配的历史步骤，摘要仍来自只读数据库；协议失配、身份不符或读取超限明确失败，不生成替代正文。
- 应用打开时读取原生会话摘要；取得新会话 id、回合结束、会话管理和项目变更后自动更新列表。工作台与 CLI 使用同一份原生会话，不以同时操作同一会话为使用前提，不提供常驻刷新入口或目录监听提示。

### F3 对话主流程

Claude、Codex 和 Antigravity 均已接入新建、续接和历史展示。接入范围与真实账号、模型回合的验证结论分开记录，内部协议的兼容性不能由界面可用推定。AGY 官方和 Gemini API 两种连接分别显示模型与偏好；官方额度仅由用户显式读取，不等同于 API Key 服务商额度或对话 token 用量。同一份本机原生记录的读取不按连接方式分组；不能把能读历史当成跨连接续发成功。Codex 仅为已核实的原生 ChatGPT 账号独立显示模型范围并按需读取官方额度；API Key 及自定义服务沿用原有配置和模型入口，不自动切换认证。

- 可在选定项目中选择支持对话的 CLI 新建会话，也可打开现有会话继续发送；续接使用原生 id，不把已显示历史重新拼成 prompt。
- 输入区的 `/resume` 可以按标题或原生 ID 查找并选择当前项目、当前 CLI 的活动会话。导航不创建会话、不提交消息；已归档会话须先恢复。
- Codex 和 Antigravity 主会话打开时先读最近几轮，向上按需加载更早的原生记录。补页保留阅读位置，单页失败不清空已有历史，也不把已经可续聊的会话锁住。
- 显示助手文本增量、工具执行与结果、错误、原生报告的用量和上下文状态；没有原生数据的字段不编造。错误条目可手动关闭，只影响所属视图的该条提示，不按局部编号删除其他会话的错误，也不改动原生历史；只读历史同一视图中的同一条错误不会因追加分页再次显示。链接目标按可渲染形态显示：可点击的保持链接，`javascript:`、`data:`、`file:` 等一律只显示文字，不追加安全策略的占位标记。
- Antigravity 续接的累计结果若只报告归属不明的错误，保留已有答复，在当前页脚与对应轮次的执行过程中提示结果未确认，不生成本轮错误条，也不自动发送待发消息；确有本轮故障仍显示错误。证据不足时不把累计结果正文冒充本轮答复，不把已完成步骤误作整轮成功。未确认状态不写入原生历史，重读只呈现原生已保存的记录。
- token 用量区分回合和步骤，平均 tok/s 只使用同范围的输出量与有效耗时；本轮暂无新值时保留本会话最近一次已加载的有效值并标注来源。上下文展示最近原生报告的用量和有效窗口比例；不能将累计输入量当上下文，也不保证重建旧会话的速度。未取得可靠用量或计时时显示缺值，不当作零。
- 提供按轮次组织的执行轨迹，查看工具调用、文件操作、命令、状态和耗时，详情按需在右栏打开。未知原生活动保留类型与状态，不把未完成记录显示为执行成功；轨迹模式保持停止与原生审批可达。
- 发送后建立可中断的运行状态，准备阶段也能停止；结束、失败或取消都应解除占用。不同会话不因共享界面而互相覆盖。
- 运行中的任务不锁定导航：可转去其他项目、会话或插件，并在另一会话发送。后台任务继续接收输出，能找回审批与停止入口；未发送草稿及各会话自己的参数不能丢失或串用。
- 同一原生会话一次只能有一个回合；运行中拒绝重复发送和改名、删除、归档、分叉。状态只表示 AgentDeck 自己的占用，不能声称外部 CLI 已被锁定。
- Claude/Codex 原生要求审批时才呈现审批操作；批准或拒绝传回对应回合。Antigravity 按原生机制展示权限模式与 stderr 软拒原因，不伪造回合内批准通道。工作台不自行添加工具放行策略，也不改写原生权限默认值。
- 模型、推理强度及权限等选项按 CLI 能力提供；未显式选择就交给原生默认。运行中的回合不偷偷切换参数，原生拒绝时显示原因，不自动换模型或重发。
- 设置可按 CLI 选择对话菜单显示的模型，并在重启后保留；当前型号始终可见，不因隐藏而改变会话参数。工作区行提供新建入口，发送后即显示本页会话，原生摘要到来后去重。运行期间持续显示当前阶段与用时，并展示 CLI 提供的公开进度，不编造未返回的思考正文。
- 会话菜单统一复制稳定链接，包含项目、CLI 与原生 ID；正文和输入区可定位本机会话。三个 CLI 分别启用只读历史工具，按原生归属检查和有界分页读取，不在粘贴时自动注入全文。
- 接入原生分叉、删除、归档等管理动作时遵守各 CLI 的真实语义。分叉只能使用服务端确认的原生结束点，源会话与项目文件保持原样；不支持的动作明确禁用或隐藏。
- 管理操作在应用内完成，不要求用户打开命令行。菜单按已接入能力提供重命名、创建分支和删除；统一归档页包括 Codex 原生归档与 Claude/Antigravity 的工作台归档，后者只存身份标记。恢复后才能续聊。跨项目操作使用被操作条目的身份；取消旧列表后必须重新触发同范围查询，不能让其他项目停在加载状态。
- 对话传输支持短暂断线补收与刷新后的本轮恢复，审批继续等待原用户决定。事件只在后端内存有界保留，浏览器仅存随机恢复身份；超时、容量不足或后端重启时说明无法恢复，绝不自动重发消息。退出应用仍结束所属任务。

- 输入支持选择、粘贴和拖放图片或文件，也可只发送附件；能力与当前模型和运行路径核对，失败保留文字和文件。每条最多8个附件、其中4张图片，单个5 MiB、合计20 MiB；格式、尺寸和动画像素预算分别校验。
- 已发送媒体从所属原生会话读取，工具图片按实际协议接入；不自动下载远程图片。独立附件缓存只保存上传资产与归属元数据，引用型文件保持固定，不能为回收空间破坏原生续聊。
- 原生问题以独立卡片显示单选、多选或自由输入；普通 MCP 表单按原生约束校验，取消、超时和撤销不生成虚构答案。回合外表单保持独立生命周期，秘密答案不回放。原生账号授权只在用户操作后进行，提交步骤与原生确认成功分开显示。不同 CLI 的阻塞问题、异步提问与追加消息按真实协议分别适配，具体协议见[原生对话](../engineering/native-dialogue.md#原生提问与表单)。

### F4 能力与配置

- 按每个 CLI、每项能力分别核实支持方式。用户级、项目级、目录级或仅运行时的作用域以原生规则为准，不要求三个 CLI 使用同一种层级。
- 常用模型和服务连接用可视表单直接写回原生用户配置；密钥默认遮蔽，点击小眼睛可查看已保存值，单纯查看不产生修改，空白保留、显式清除。既有高级认证和未知字段不能被简化表单覆盖；具体字段与生效范围见[原生配置](../engineering/native-configuration.md)。
- 模型、命令、Skills、MCP、规则、原生插件和权限能力从该 CLI 的有效接口或配置获得；未知、未支持、无权限和尚未接入应区分。
- 三个 CLI 均提供当前版本、手动检查新版、安装、更新和修复。管理范围包括能识别的官方独立命令行安装及 npm 安装。更新与该 CLI 的回合、原生读写互斥，实际使用该份安装的进程须由用户自行关闭。新版通过最终入口、目标版本及工作台接口验证后才能清理旧版。安装或验证失败时恢复原有安装。对历史残留，仅清理能确认属于同一份安装且已经不用的旧件。
- `/` 补全只能来自真实能力目录。未知、禁用或歧义命令不能静默当普通消息发送；需要会话的命令在无会话时提示限制。
- 原生文件编辑保留未知字段与原格式，检查文件身份和外部修改；JSON/TOML 按格式校验，规则文本由 CLI 解释。缺失、空白和读取失败分别展示，显式保存才写盘；固定规则和 Skills 根目录支持受控创建。
- 记忆设置遵循 CLI 原生能力：Claude Code 在设置页提供用户级启用与关闭，并保留其他配置且不向前端传记忆正文；项目级启用留给项目原生设置。其他 CLI 未确认独立自动记忆开关时，提供规则文件入口而不虚构统一开关。
- 通用设置保存本机界面偏好：每项目默认展示的会话条数（默认 5，可调 1–20）与对话区宽度（小 720、中 860、大 1040，或 480–1400 自定义，默认「中」）。两项与其他产品偏好一起走显式保存，读不到设置时退回默认值。
- 默认目录视图只返回元数据，不预读敏感正文。用户点击显示并编辑后才读取完整文件，正文随编辑器关闭释放，不进入共享缓存或浏览器存储；保存响应、日志和错误不回显正文。该显式原文入口与启动环境的常规状态接口分别约束。
- 启动环境只补足原生配置之外的实际需要。按 CLI 白名单管理变量，状态区分继承、显式配置、停用和未设置；高级“CLI 环境变量”页单独保存后，已有实例由用户显式重启才采用新值。模型与连接表单保存时自动回收空闲实例，URL 和 Key 在下一次发送时加载。
- 启动环境的敏感值加密保存，已保存的密钥按点击单独读取；禁止用该入口设置 `PATH`、`NODE_OPTIONS`、`PYTHONPATH` 等加载行为变量。不得读取其他配置切换工具的私有数据库。
- AGY 官方账号设置显示原生确认的邮箱，Windows 桌面端可从旁边打开原生交互登录，不接收授权码、不切换 API Key。一个可选代理地址用于工作台启动的 AGY 的 HTTP 和 HTTPS，不影响进行中的回合、系统或其他 CLI。

### F5 扩展插件

- 提供 AgentDeck 自有接口，工作台新增业务通过插件接入。CLI 原生插件仍属于相应 CLI，不转成工作台插件格式。
- v1 外部扩展采用本地静态页面包，可声明页面命令、自己的设置存储和当前项目摘要权限；不运行外部 Node 后端代码。安装后默认停用，用户检查权限后启用。
- 插件的安装、启停、资源清理和版本兼容须有明确行为；关闭页面与停用插件是不同动作。
- SSH Console 是首个业务插件。优先复用已验证的 SSH 业务和成熟组件，避免为插件化再写一套相同业务。
- 不提供 DSH 插件原样安装、包格式兼容或长期维护的适配层。

### F6 SSH Console

内置 SSH Console 已按现有插件的独立工具体验接入，并且只以服务器为单位：服务器清单来自服务器档案，页面内没有项目这一层，服务器操作也不再占用对话右栏。

- 从侧栏进入独立主页面；服务器清单来自服务器档案，也读取 `~/.ssh/config` 导入选项。多台服务器保持连接，以标签切换当前目标，页面提供概览、进程、作业、文件和终端。
- 概览展示 CPU、内存、负载、磁盘、GPU 利用率及显存；进程页展示 GPU 与系统进程，作业页只读展示当前登录账号的 `squeue`。缺失值不补零，旧读数标明过期；仅当前可见目标持续采样。
- 文件页只读列目录并预览文本，预览取开头最多 256 KiB；不包含新建、移动、删除、上传或下载按钮。终端仍是用户自己的通用 SSH shell。
- 同台服务器可持有多个 PTY；切换页签、服务器或关闭插件页面后重新打开，应能接回仍存活的终端。真正关闭终端、断开服务器或停用插件才回收相应资源。
- 终端提供本机回滚查找；打开查找和跳转命中不向远端发送命令。输入及输出的结果不确定时不自动重发按键。
- 服务器独立于本地项目，页面内没有项目这一层：不需要绑定项目，也不存在项目提供的默认目标。服务器档案只由连接名称标识。
- 认证支持已有私钥和密码，必须校验主机密钥。未知主机先确认指纹，密钥变更或吊销明确拒绝；浏览器不能读取私钥内容。
- 控制台使用独立服务器档案、主机信任和可选加密密码。停用时明确提示并结束控制台终端，保留档案、凭据、项目、原生历史及共享连接。
- 成功停用后关闭控制台内所有终端并释放页面状态；重新启用从空列表开始，由用户选择服务器并新建终端。停用失败或用户取消时不提前清理有效终端。

### F7 桌面与通用交互

- 产品入口是 Electron 窗口，本机 Fastify 服务由其管理，单实例运行，退出时清理后端与子进程；浏览器入口用于调试。
- 视觉与信息组织对齐 DSH：左侧工作区、中间对话、可打开的右侧栏；使用中性灰阶、细边框和系统字体，代码与路径采用等宽字体。三个 CLI 不分别设计三套风格。
- 桌面品牌与 File/Edit/View 等菜单处于同一标题栏，保留系统窗口控制和快捷键；浮层展开不挤动项目树。正常会话自动更新，异常时才提供重试；配置说明按需展开，不占据主流程。
- 左栏上方提供新建与插件入口，项目下的会话按最近活动混合排列，来源清楚可见；设置和外观在左栏底部。中央标题栏只承担当前会话标题与状态。
- 侧栏宽度、折叠和窄窗互斥按[界面尺寸](ui-layout.md#11-宽度与收起)处理；右栏每次启动关闭，不复用旧服务器面板的展开偏好。
- 右栏提供会话信息、配置入口和选中轨迹步骤的详情，不宣称提供 IDE、文件树或独立改动列表。插件占用中央主区，打开/关闭右栏及切插件返回不得清空对话草稿。宽度冲突时协调左右栏，具体边界见[界面约定](ui-layout.md)。
- 加载、空态、读取失败和能力缺失各有可理解的说明；输入法组字时不触发发送或快捷命令。
- 原生事件没有提供的信息不通过扫描整个项目推断；不恢复每轮 Git 快照、独立改动汇总和行内反馈系统。
- 本地分发提供 Windows x64 的 NSIS 与 portable 构建，产品数据与程序分开。当前不签名、不上传发布、不自动更新；生成包、包内启动和实际安装卸载分别验收。

## 3. 请求与数据边界

| 动作 | 触发约束 |
|---|---|
| 本机可执行文件与接口探测、读取配置/会话 | 可随启动、导航及应用内操作读取；仅运行本地操作 |
| 登录/模型/命令能力检查 | 首次打开模型菜单且尚无原生目录时自动读取，或用户手动刷新；可能鉴权联网，失败不循环重试 |
| AGY 临时窗口模型的默认强度 | 发送准备阶段未显式指定强度时，可读取隔离的本机内置目录并缓存；占位认证、外部请求阻断，不发送模型请求 |
| prompt 与真实模型回合 | 仅用户明确发送；新建页面、切项目、重连均不等于发送 |

后端自己不调用模型 HTTP 端点，模型请求由 CLI 进程完成。项目、偏好和必要元数据可以保存；对话正文、工具事件和附件不落成独立 transcript。已发送但结果不确定的操作不得通过自动重发掩盖。

后端只监听本机地址，并校验 Host、Origin 与会话 Cookie。凭据、真实服务器信息和用户会话不得进入公开仓库；例子使用 `my-server`、`~/projects/demo` 等虚构值。
