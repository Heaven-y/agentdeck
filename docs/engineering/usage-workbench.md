# 用量工作台

用量页是 AgentDeck 内置功能，从侧栏底部“用量”打开。它读取已登记工作区的原生会话计量，提供日期、CLI、工作区、供应方及模型筛选、小时/日趋势、分页记录和缓存比例。同步由用户启动，可暂停；离开页面取消当前请求，回来可以继续。页面使用工作台已有主题和控件。

## 公共接口与原生适配

共享协议位于 `packages/shared/src/usage`，服务在 `apps/server/src/usage`，前端在 `features/usage`。各 CLI 的 `usage/records.ts` 实现 `UsageProvider`：按来源身份读取一页，仅返回计量投影和继续游标。原生目录发现、会话归属仍复用现有会话模块；公共服务负责索引、分页、筛选、聚合和价格计算，不解释各 CLI 的私有字段。

| 来源 | 读取方式 | 计量范围 |
|---|---|---|
| Claude Code | SDK 会话及子代理分页消息 | 按 API message.id 合并同一回复的内容块；历史输出可能非最终，不并入完整输出汇总 |
| Codex | 原生 thread/read 给出的文件路径，再有界读取 rollout | 只接收属于该线程的 TokenUsageRecord 单响应计数；父历史和累计快照不重复累加 |
| Antigravity | 原生 FULL 生成目录分页，以及关联步骤的时间与身份 | 按执行身份和生成索引计数；子代理沿已验证父链读取，完整生成计时才显示 |

Codex 展示历史接口本身不包含用量，原始文件读取属于统计适配器。它的 input_tokens 包含缓存读取和写入，适配后纯新增输入扣除两者；零值可能来自原生解析器的缺省，不能解释为供应方明确报告。Claude、AGY 的新输入与缓存按各自实际报告归一，推理量不再加到已包含它的输出中。

## 指标含义

- 已记录生成：具有可靠原生身份和时间的生成记录数，不是包含所有失败与重试的 HTTP 请求数。
- 输入、输出、缓存：只加和已取得且口径一致的分项。未报告与未确认最终输出保留缺失；详情保留原生来源与输出完整性。
- 缓存命中率：缓存读取占已报告输入的比例；有原生输入总量时优先使用该值，其余按已记录分项计算。跨记录按分子分母加总，不平均各条百分比。
- 已知用量估价：自动匹配官方标准文本 API 参考价；用户覆盖按 CLI、模型和供应方精确匹配，未匹配型号留空。只对可计量分项估算。它不表示实际账单或订阅配额消耗。
- 型号：优先原生响应型号；只有当时配置的来源明确标为配置型号，不拿当前默认模型填旧记录。
- 生成时长与首段等待：仅在同次原生生成可核验时显示，不把工具等待或整轮时间包装成逐请求速度。

缓存命中率按阈值着色：80% 及以上绿色，50% 至不足 80% 使用普通文字，低于 50% 使用琥珀色。数字本身始终显示，不标记前后下降，不判定故障。

## 官方参考单价

内置目录 `apps/server/src/usage/official-prices.json` 于 2026-11-26 核对三家官网，覆盖 71 个精确型号、75 个日期费率条目与 13 个明确别名。来源为 [OpenAI](https://developers.openai.com/api/docs/pricing)、[Anthropic](https://platform.claude.com/docs/en/about-claude/pricing)、[Google Gemini](https://aistudio.google.com/docs/pricing)，各条记录保留官网链接及核验日期。单价页默认展示当前参考价，支持搜索及自定义覆盖；新增模型目录不改变 CLI 模型候选或权限。

估价使用标准文本 API 参考价；供应方自定义或订阅会话仍可据此比较计量消耗，不表示供应方实际收费。长上下文按含缓存总输入对整次生成选择分档；缺少分档依据时不猜测。缓存写入有不同 TTL 时，只有原生保存了对应分项才计价：Claude 使用 5m/1h，OpenAI 新型号支持 30m/12h。旧 OpenAI 无额外写入费的模型按普通输入价计算该部分；Gemini 的显式缓存存储按时间收费，不混入写入 token 价格。

已公布调价按记录日期选档；官网仅给生效日期时，以 UTC 日边界作参考估算。当前目录未核实旧价格起始日的条目作为现价参考，不声称还原所有历史账单；已到期且没有后续报价的促销留空。官网新价格需更新随包目录，本版不后台抓站或自动改变用户覆盖。

## 索引与生命周期

`usage.sqlite` 保存在工作台配置目录，只含计量、时间、模型及关联身份，不保存提示词、回复和工具正文。一次原生会话全部页读取成功后才替换它的指标集合；失败保留已有索引。重复同步与分支副本按原生响应身份去重，只有合法工作区的记录参与查询。目录更换或工作区移除后，旧目录的指标不进入新目录结果。

同步按原生会话页、生成页推进；分页请求共用一个批次，可取消后继续。CLI 更新与统计读取使用同一维护租约，工作区目录变更与读取也使用已有活动锁。Claude SDK 的每页 200 条限制的是返回投影：内部可能整读文件，且较大的主历史可能略过压缩前记录，因此统计覆盖 SDK 可回放的记录。SDK 不接受取消时只停止宿主等待并消费迟到结果；原生 IO 仍可能继续。

原生 JSONL 按块扫描，单源各页先写入 SQLite 临时索引，完成后事务替换；查询通过 SQLite 逐行迭代并只保留当前记录页和聚合结果，不以文件字节数、总记录数设读取门槛。页面每次显示 100 条，更多记录继续翻页。AGY 子任务发现按步骤窗口只投影关系，Codex 按原生轮次页只保留父子关系条目，不把完整正文作为统计索引的前提。后续增量优化应依据原生 revision/游标，不能只因父会话摘要未变就跳过仍在运行的子任务。

## 扩展归属

基础概览、原生记录和缓存比例属于内置能力；原生差异留在适配器。需要额外 OTel 采集、供应商账单账号或定制外部报表时，可由工作台插件承接，并复用宿主数据模块。当前不安装额外采集器、不注入其他应用，也不接管模型流量；尚无插件消费者时，不增加一套独立的通用采集框架。

本轮 AGY 原生读取验证取得根与子任务计量、未发模型请求且会话轨迹数据库未变；管理进程启动时摘要库有变化，不能称所有原生数据库物理只读不变。
