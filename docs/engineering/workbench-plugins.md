# 工作台插件接口 v1

本文描述插件契约和页面关系，交付与验收状态见[路线图](../roadmap.md)。

AgentDeck 插件与 CLI 原生插件分别管理。第一版支持本地静态页面插件，提供自己的设置存储、当前项目摘要和命令入口；SSH Console 是使用宿主服务的内置插件。外部包不执行 Node.js 后端代码，也不兼容 DSH 的包格式。

## 插件包

插件目录包含 `agentdeck.plugin.json` 与自包含 HTML 入口。脚本和样式打入 HTML，图片可使用 data URI。安装复制到产品自己的插件目录，不在来源目录执行安装脚本，也不写入用户项目。

```json
{
  "id": "project-helper",
  "name": "项目助手",
  "version": "1.0.0",
  "apiVersion": 1,
  "entry": "index.html",
  "description": "显示当前项目与插件自己的设置",
  "permissions": ["storage", "project-context"],
  "commands": [{"id": "open", "title": "打开项目助手"}]
}
```

本地目录安装后默认停用，用户查看权限后启用。v1 拒绝其他 API 主版本、重复身份、路径越界、符号链接和可执行来源文件。单包最多 10 MiB、256 个文件、8 层目录；命令最多 32 项。只有安装时登记的入口摘要一致才可显示页面。

内置插件支持停用与再启用，不提供卸载。外部插件卸载时删除安装副本和插件设置，保留来源目录。启停和卸载核对 registry revision，资源清理失败时报告具体状态。

## 页面与宿主 API

插件管理和已启用插件位于工作台左栏上方。打开插件后使用中央主区，暂时隐藏对话与会话信息右栏；返回对话保留当前会话、草稿及本次右栏选择。页面只有一份标题，业务动作放在相应工具栏。

宿主显式取得已启用插件的 HTML，放入只允许脚本的 sandbox iframe。页面没有同源权限、Node 权限、表单提交或任意网络访问；不会获得 Cookie、认证变量、会话正文和 SSH 凭据。主应用的 Host/Origin/会话检查不为插件放宽。

页面可调用宿主注入的 `window.agentdeck`：

| 接口 | 所需权限 | 结果 |
|---|---|---|
| `agentdeck.storage.get()` | storage | `{ value, revision }`，插件自己的 JSON 设置 |
| `agentdeck.storage.set({ value, revision })` | storage | 核对版本后保存并返回新 revision，最多 64 KiB |
| `agentdeck.project.get()` | project-context | 当前 `{ id, name, dir }` 或 null；不返回服务器绑定和会话 |
| `agentdeck.onCommand(callback)` | 无 | 菜单命令打开插件页面并通知命令 id；返回取消订阅函数 |

宿主检查消息来自对应 iframe，按声明权限处理固定方法；单页面最多 16 个并发请求和每秒 60 次调用。设置是普通业务数据存储，不作为凭据保险库。外部页面异常不应影响对话与其他插件。

关闭外部插件页面会卸载 iframe，插件自己的持久设置保留；重新打开会重新读取。停用会撤销页面和接口访问。CLI 的配置、Skills、MCP 以及原生插件仍走[原生配置入口](native-configuration.md)。

## SSH Console

SSH Console 通过同一插件目录展示和启停，主页面包含独立服务器标签、概览、进程、作业、只读文件与终端。服务器 alias 是唯一目标身份；项目不提供默认服务器或目录，也不创建隐藏项目来连接服务器。

控制台首次进入时挂载，离开页面后以隐藏且不可聚焦的状态保留组件；资源、进程与作业采样同时停用。切换对话、打开会话右栏或切换项目不重建既有控制台页面，不覆盖已选服务器；打开时没有选中服务器，由用户从选择器决定。

底层复用现有 SSH 连接池、主机信任和系统加密凭据。控制台的 PTY 由后端按服务器持有，关闭页面与关闭终端不同；每服务器最多 6 个，全局最多 32 个。输出保留最近 512 KiB，以字节游标读取，过期游标明确重置。断开服务器、身份代次变化、停用插件或应用退出会回收相应通道。

文件页只使用 SFTP 的目录读取与常规文件预览，预览最多 256 KiB。资源、进程与作业只对当前可见服务器采样，缺失与过期分别呈现。停用会结束控制台中的终端并释放页面状态；服务器档案、密码密文与项目保留，共享连接不因插件停用而整体断开。

服务器档案与项目相互独立，档案修改和删除按 revision/expected 快照校验并发更新。Slurm 位于控制台的只读「作业」页。

停用成功后重新启用从空列表开始，由用户显式选择服务器并新建终端；不能用遗留状态重建 shell。停用取消或失败时保留当前标签和连接。真正结束的终端由用户显式新建，不通过自动重连伪装为原终端恢复。

## 内置注册与存储

后端由 bootstrap 注入内置 manifest 与生命周期注册。插件路由统一检查启用状态；停用时释放控制台通道并使在途租约失效，连接池在应用退出时关闭。服务器档案与用户密码沿用原磁盘路径。

前端注册项提供页面、图标、排序、停用说明和成功后的清理动作；通用宿主保留页面可见性和外部 iframe 权限。插件目录清单 v1 保持不变。宿主自身 registry 的存储升级为 v2 `builtinEnabled` 映射；v1 的 `sshConsoleEnabled` 按原值读入，只在用户下一次保存时写新格式，不在启动读取时改盘。

## 控制台交互补齐

独立概览以服务器为单位缓存全部真实文件系统，过滤伪文件系统和 loop 镜像；每个挂载点分别显示占用与剩余空间。负载保留 1/5/15 分钟窗口，核数已知时增加每核一分钟负载；系统信息和运行时长缺失时省略。

作业页原样等宽显示当前登录账号的 `squeue` 输出，标明采样时间；未安装 Slurm、查询失败、无排队作业与输出截断分别呈现，不把不可用呈现成空列表。

GPU 和 Top 进程表可折叠，每张卡独立展示进程数量及已知显存合计。文件页提供最近 50 次成功访问的前后导航、面包屑和可取消的路径编辑；失败不会修改当前位置，预览仍只读。

单终端分屏可创建第二个 shell，点击窗格决定随后标签替换的位置，取消分屏保留当前终端。搜索只扫描本地 5000 行缓冲，组字期间不搜索；完整计数支持中文宽字符和软换行，高亮装饰最多 1000 处，超出仍可跳转和计数。
