# 工作台插件

本文说明工作台插件的管理、v1 扩展接口和内置插件的用法。CLI 自己加载的插件见[原生配置](native-configuration.md#原生插件管理)。

## 插件包

v1 支持自包含的本地静态页面。插件目录包含 `agentdeck.plugin.json` 和 HTML 入口，脚本和样式放在 HTML 中，图片可使用 data URI。安装复制到工作台的插件目录，不执行来源脚本或更改项目。安装器按 AgentDeck 的插件契约校验包。

```json
{
  "id": "project-helper",
  "name": "项目助手",
  "version": "1.0.0",
  "apiVersion": 1,
  "entry": "index.html",
  "description": "显示当前项目与插件自己的设置",
  "permissions": ["storage", "project-context"],
  "commands": [{"id": "open", "title": "打开项目助手"}]
}
```

本地目录安装后默认停用，用户查看权限后启用。v1 拒绝其他 API 主版本、重复身份、路径越界、符号链接和可执行来源文件。单包最多 10 MiB、256 个文件、8 层目录；命令最多 32 项。只有安装时登记的入口摘要一致才可显示页面。

内置插件支持停用与再启用，不提供卸载。外部插件卸载时删除安装副本和插件设置，保留来源目录。启停和卸载核对 registry revision，资源清理失败时报告具体状态。

## 页面与宿主 API

从左栏的插件管理安装和启停；已启用的插件可从侧栏或命令面板打开。工作台在中央主区展示插件，返回对话恢复会话、草稿和右栏状态。

宿主显式取得已启用插件的 HTML，放入只允许脚本的 sandbox iframe。页面没有同源权限、Node 权限、表单提交或任意网络访问；不会获得 Cookie、认证变量、会话正文和 SSH 凭据。主应用的 Host/Origin/会话检查不为插件放宽。

页面可调用宿主注入的 `window.agentdeck`：

| 接口 | 所需权限 | 结果 |
|---|---|---|
| `agentdeck.storage.get()` | storage | `{ value, revision }`，插件自己的 JSON 设置 |
| `agentdeck.storage.set({ value, revision })` | storage | 核对版本后保存并返回新 revision，最多 64 KiB |
| `agentdeck.project.get()` | project-context | 当前项目的 `{ id, name, dir }` 或 null |
| `agentdeck.onCommand(callback)` | 无 | 菜单命令打开插件页面并通知命令 id；返回取消订阅函数 |

宿主检查消息来自对应 iframe，按声明权限处理固定方法；单页面最多 16 个并发请求和每秒 60 次调用。设置是普通业务数据存储，不作为凭据保险库。外部页面异常不应影响对话与其他插件。

关闭外部插件页面会卸载 iframe，保留它的持久设置；重开时由插件读取。停用会撤销页面和接口访问。

## 内置注册与存储

后端由 bootstrap 登记内置插件的 manifest 和生命周期；路由统一检查启用状态，停用与退出调用各自的资源清理。

前端注册项提供页面、图标、排序、停用说明和成功后的清理动作；通用宿主保留页面可见性和外部 iframe 权限。插件目录清单 v1 保持不变。宿主自身 registry 的存储升级为 v2 `builtinEnabled` 映射；v1 的 `sshConsoleEnabled` 按原值读入，只在用户下一次保存时写新格式，不在启动读取时改盘。

## SSH Console

SSH Console 是内置的服务器管理插件，启用后可从侧栏打开。先从选择器选择服务器，再用标签在多台已连接服务器间切换。无需创建本地项目；服务器档案可以手动添加或从 `~/.ssh/config` 导入。

### 页面与操作

| 页面 | 用法 |
|---|---|
| 概览与进程 | 查看 CPU、内存、1/5/15 分钟负载、各挂载点的占用与可用空间，以及 GPU 利用率和显存。已知核数时显示每核负载；进程表可折叠，显示系统进程及按卡分组的 GPU 进程 |
| 作业 | 只读查看当前登录账号的 Slurm 作业及采样时间；按原样显示 `squeue`，区分无作业、未安装、查询失败和输出截断 |
| 文件 | 通过面包屑或路径进入目录，前后导航保留最近 50 次成功访问；浏览名称、修改时间等元数据和文本预览。目录和预览均只读 |
| 终端 | 同一台服务器可开多个终端。分屏优先使用另一已开终端，只有一个时可新建；点击窗格后可在该位置换标签，取消分屏保留当前终端。`Ctrl+F` 或 `Meta+F` 在本机回滚缓冲中查找，显示高亮与命中序号，关闭查找后焦点回到终端 |

只有当前可见且已连接的服务器页面发起监控：概览与进程的刷新间隔为 2 秒，作业页为 10 秒。读数缺失与过期分别显示。切回对话、切项目或切服务器不结束 shell；返回时接回仍在运行的终端。终端输入失败时保留已收到的输出，未确认的按键不会重发。若连接已结束，需新开终端。

关闭终端只结束对应 shell；断开服务器会回收该服务器的通道。停用插件前提示将关闭控制台及其中的终端。成功停用会释放控制台的通道和页面状态，保留服务器档案、保存的凭据和共享连接；取消不会关闭终端。若清理完成后保存失败，插件可能仍显示为启用，已经关闭的终端需要重新打开。重新启用后重新选择服务器，按需新建终端。

### 实现与资源约束

- 服务入口：`/api/ssh-targets`、`/api/ssh/*` 管档案、认证和信任；`/api/ssh-console/:serverId/*` 管控制台。后端以档案的稳定 alias 定位，最多 128 条档案，以主机、端口、账号去重，revision/expected 快照保护并发修改。导入读取 SSH 配置文件，保留不支持的选项提示。
- 支持已有私钥或密码；未知主机的 SHA-256 指纹经用户确认并写入 `known_hosts` 后，才使用凭据连接。一次性挑战有效 2 分钟，最多同时保留 32 项；密钥变更或吊销时拒绝连接。私钥正文留在后端。密码仅保留在内存或使用当前 Windows 用户的 DPAPI 加密，编辑时显式读取且返回 `no-store`。
- 底层复用 SSH 连接，exec、SFTP 和 PTY 使用独立通道。断开或认证变化后递增连接代次并失效旧租约，结束、取消或超时只清理对应通道。应用退出时关闭连接池。
- 监控用 `/proc`、`df`、`ps` 和 `nvidia-smi` 等远端已有接口，单次采样超时 25 秒。作业用当前登录账号的 `squeue`，查询预算 8 秒、512 KiB、200 行。只读命令共用 `console/command.ts` 的租约通道及按代次区分的缓存。文件页使用 SFTP，目录最多 400 项，文本预览最多读取开头 256 KiB，超限标明截断。通用限额见 [SSH 协议常量](../../packages/shared/src/ssh/console.ts)。
- 后端每台服务器最多 6 个 PTY，全局 32 个，输出保留最近 512 KiB。HTTP 读取返回 base64 字节和 `nextSeq`，浏览器消费后才推进；游标早于保留范围时重置。输入单帧最多 32 KiB、待写 256 KiB。xterm 直接接收字节，未知退出码保持为空，多行粘贴需要确认。终端查找只搜索本机 5000 行回滚缓冲，不向服务器发命令，高亮最多 1000 处，更多命中仍可计数、跳转。

## 扩展验收

- 工作台插件：可安装符合 v1 的外部包，核对权限后启停；分别验证关闭页面、停用和卸载的状态与资源变化。
- 内置控制台：首次启动工作台时未打开控制台不发 SSH 请求；没有本地项目也可连接。多服务器的标签与通道互相隔离，文件预览只读，切页保留仍存活的终端，关闭或停用结束相应资源，主机身份检查始终生效。
- 既有记录：一台服务器通过资源、SFTP 读取、PTY 创建/调整/输出/关闭及 Slurm 只读查询，另一台连接失败，后续从网络和认证环节排查。该次核对是只读查询与终端操作，保留配置与主机信任。原始记录见 `b053fe1:docs/roadmap.md`。深浅主题、不同宽度、分屏、搜索及文件导航的界面验证见 `b053fe1`、`02ce382`。
